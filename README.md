# E2E Chat (端到端加密聊天)

这是一个基于 Rust 实现的端到端加密聊天程序，使用 X25519 进行密钥交换和 AES-256-GCM 进行消息加密。

## 用法

启动服务器:
```bash
cargo run -- server
```

启动客户端:
```bash
cargo run -- client <服务器IP:端口>
```

## 功能特点

- 端到端加密：服务器无法解密用户之间的通信内容
- 密钥交换：使用 X25519 椭圆曲线算法进行安全的密钥协商
- 消息加密：使用 AES-256-GCM 算法进行消息加密和完整性验证
- 盲目转发：服务器仅负责转发加密消息，无法获取明文内容
